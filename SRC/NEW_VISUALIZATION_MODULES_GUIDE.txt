========================================================================
MODULE 1: INTER-EVENT INTERVAL (IEI) ANALYSIS
========================================================================

File: plot_iei_comparison.m

PURPOSE:
Reveals temporal patterning of spontaneous events - are they regular
(periodic) or random (Poisson-like)?

WHAT IT SHOWS:
- IEI distribution (log and linear scale)
- Cumulative IEI distribution
- Box plot comparison with statistical test
- Coefficient of variation (CV) - regularity metric
  * CV = 1: Random (Poisson)
  * CV < 1: Regular/periodic
  * CV > 1: Bursting/irregular

USAGE:
```matlab
% Standalone
plot_options = struct('frame_rate', 100, 'max_iei_s', 10);
fig = plot_iei_comparison(results, plot_options);

% Within integrated analysis (automatic)
options.create_iei_plot = true;
results = integrated_batch_analysis_final(folder_path, options);
```

SCIENTIFIC VALUE:
- Tests if R213W mutation affects temporal regularity of release
- CV differences suggest altered stochastic vs regulated release
- Median IEI gives typical inter-event time

========================================================================
MODULE 2: AMPLITUDE-FREQUENCY CORRELATION
========================================================================

File: plot_amplitude_frequency_correlation.m

PURPOSE:
Tests if high-frequency ROIs have different amplitude characteristics

WHAT IT SHOWS:
- Scatter plots with marginal histograms (WT and R213W separately)
- Combined overlay comparison
- Spearman correlation coefficients
- Linear trend lines

USAGE:
```matlab
% Standalone
fig = plot_amplitude_frequency_correlation(results);

% Within integrated analysis (automatic)
options.create_amp_freq_correlation = true;
results = integrated_batch_analysis_final(folder_path, options);
```

SCIENTIFIC VALUE:
- Positive correlation: Larger events occur more frequently
- Negative correlation: Rare large events, frequent small events
- No correlation: Independent amplitude and frequency regulation
- Tests if mutation affects amplitude-frequency coupling

========================================================================
MODULE 3: EVENT TIMING RASTER PLOTS
========================================================================

File: plot_event_raster.m

PURPOSE:
Visual assessment of event timing across population

WHAT IT SHOWS:
- Raster plot (each row = one ROI, marks = event times)
- Population event rate over time (events/s)
- Temporal patterns: bursts, clusters, or uniform distribution
- Coefficient of variation of population rate

USAGE:
```matlab
% Standalone
plot_options = struct('frame_rate', 100, ...
                     'max_rois_per_plot', 100, ...
                     'recording_duration_s', 30);
fig = plot_event_raster(results, plot_options);

% Within integrated analysis (automatic)
options.create_event_raster = true;
results = integrated_batch_analysis_final(folder_path, options);
```

SCIENTIFIC VALUE:
- Reveals synchronized vs asynchronous activity
- Detects network-level events or oscillations
- Shows if mutation affects temporal coordination

========================================================================
MODULE 4: BIOLOGICAL VARIABILITY ANALYSIS
========================================================================

File: plot_biological_variability.m

PURPOSE:
Shows consistency across biological replicates (coverslips)

WHAT IT SHOWS:
- Box plots with individual data points overlaid (per file)
- Metrics: frequency, amplitude, active ROI fraction, total events
- Coefficient of variation (CV) for each metric
- Statistical tests between conditions

USAGE:
```matlab
% Standalone
fig = plot_biological_variability(results);

% Within integrated analysis (automatic)
options.create_biological_variability = true;
results = integrated_batch_analysis_final(folder_path, options);
```

SCIENTIFIC VALUE:
- Assesses experimental reproducibility
- Identifies outlier experiments
- Lower CV = more consistent phenotype
- Critical for publication quality

- Both absolute counts and percentages

USAGE:


SCIENTIFIC VALUE:

- More informative than single "active %" metric
- Shows full spectrum of activity levels

========================================================================
MODULE 6: CUMULATIVE EVENT COUNT OVER TIME
========================================================================

File: plot_cumulative_events_over_time.m

PURPOSE:
Detects if activity changes during recording (rundown, buildup)

WHAT IT SHOWS:
- Cumulative event count curves (normalized to 1.0)
- Instantaneous event rate over time
- Linearity metrics (R²)
- Early vs late rate comparison

USAGE:
```matlab
% Standalone
plot_options = struct('frame_rate', 100, 'recording_duration_s', 30);
fig = plot_cumulative_events_over_time(results, plot_options);

% Within integrated analysis (automatic)
options.create_cumulative_events = true;
results = integrated_batch_analysis_final(folder_path, options);
```

SCIENTIFIC VALUE:
- Linear curve (R² ≈ 1): Constant activity
- Upward curvature: Buildup/sensitization
- Downward curvature: Rundown/desensitization
- Tests if mutation affects activity stability

========================================================================
TROUBLESHOOTING
========================================================================

PROBLEM: "Undefined function 'plot_iei_comparison'"
SOLUTION: Ensure all new .m files are in your MATLAB path. Run setup_pipeline.

PROBLEM: "Expected 1200 frames, got 3000"
SOLUTION: This is just a warning. The code handles 3000 frames correctly.
         To suppress, set options.frame_rate = 100 explicitly.

PROBLEM: Plots look empty or have missing data
SOLUTION: Check that your data actually contains events. Run:
         fprintf('WT events: %d\n', results.wt_data.total_events);
         fprintf('R213W events: %d\n', results.mut_data.total_events);

PROBLEM: "Insufficient data for CV analysis"
SOLUTION: You need ROIs with multiple events (≥2) for inter-event intervals.
         This is normal if you have many ROIs with only 1 event.

PROBLEM: Out of memory errors
SOLUTION: Set options.create_event_raster = false; (raster plots use most memory)
