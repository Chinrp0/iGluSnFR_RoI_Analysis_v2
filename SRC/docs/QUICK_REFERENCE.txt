========================================================================
FUNCTION CALL SIGNATURES
========================================================================

All functions follow the same pattern:
    fig = function_name(results, options)

Where:
- results = output from integrated_batch_analysis_final()
- options = struct with plotting preferences (optional)
- fig = figure handle (can be saved, modified, etc.)

Common options:
- options.frame_rate = 100  % Hz (REQUIRED for timing analysis)
- options.recording_duration_s = 30  % seconds
- options.max_rois_per_plot = 100  % For raster plots
- options.max_iei_s = 10  % For IEI plots

========================================================================
WHAT EACH MODULE REVEALS
========================================================================

IEI ANALYSIS:
→ Are events regular (periodic) or random (Poisson)?
→ CV < 1: Regular, CV = 1: Random, CV > 1: Bursting
→ Tests temporal patterning differences between WT and R213W

AMPLITUDE-FREQUENCY CORRELATION:
→ Do high-frequency ROIs have larger or smaller events?
→ Positive r: frequent = large, Negative r: frequent = small
→ Tests if release amplitude and frequency are coupled

EVENT RASTER:
→ Are events synchronized across population?
→ Reveals bursts, oscillations, or independent firing
→ Population rate changes over recording

BIOLOGICAL VARIABILITY:
→ How consistent are measurements across replicates?
→ Lower CV = more reproducible phenotype
→ Identifies outlier experiments

ROI RECRUITMENT:
→ At what frequency threshold do conditions diverge?
→ More informative than single "active %" metric
→ Shows full spectrum of activity levels

CUMULATIVE EVENTS:
→ Does activity increase (buildup) or decrease (rundown)?
→ Linear (R² ≈ 1) = stable activity
→ Curvature indicates activity changes over time

========================================================================
SELECTIVE PLOTTING
========================================================================

To skip specific plots:

```matlab
options.create_iei_plot = false;  % Skip IEI
options.create_amp_freq_correlation = false;  % Skip correlation
options.create_event_raster = false;  % Skip raster (memory-intensive)
options.create_biological_variability = false;  % Skip variability
options.create_recruitment_curves = false;  % Skip recruitment
options.create_cumulative_events = false;  % Skip cumulative
```

Or create ONLY specific plots:

```matlab
% Disable all
options.createPlots = false;

% Run analysis
results = integrated_batch_analysis_final(folder_path, options);

% Manually create just what you need
fig1 = plot_iei_comparison(results, struct('frame_rate', 100));
fig2 = plot_biological_variability(results);
```
