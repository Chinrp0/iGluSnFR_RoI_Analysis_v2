ISSUE 1: IEI Box Plot Concatenation Error (CRITICAL)
=================================================================

LOCATION: plot_iei_comparison.m, lines 95-96

SYMPTOM:
--------
Error using horzcat
Dimensions of arrays being concatenated are not consistent.

ROOT CAUSE ANALYSIS:
--------------------
The code attempted horizontal concatenation of two column vectors:
  • wt_ieis_plot: [1576×1] column vector
  • mut_ieis_plot: [2012×1] column vector

MATLAB requires horizontal concatenation [a, b] to have:
  ✓ Same number of rows
  ✗ Different number of columns

Since 1576 ≠ 2012, horizontal concatenation fails!

INCORRECT CODE (Lines 95-96):
------------------------------
all_ieis = [wt_ieis_plot, mut_ieis_plot];  % Tries: [1576×1, 2012×1] → ERROR
groups = [ones(1, length(wt_ieis_plot)), 2*ones(1, length(mut_ieis_plot))];

Why This Failed:
• Horizontal [a,b] creates a matrix with 2 columns
• MATLAB cannot create a matrix with columns of different heights
• boxplot() expects a single column vector + group labels

CORRECTED CODE (Lines 95-97):
------------------------------
% FIXED: Vertical concatenation for boxplot (both are column vectors)
all_ieis = [wt_ieis_plot; mut_ieis_plot];  % Vertical: [1576×1; 2012×1] → [3588×1] ✓
groups = [ones(length(wt_ieis_plot), 1); 2*ones(length(mut_ieis_plot), 1)];

Why This Works:
• Vertical [a;b] stacks arrays vertically
• Creates single column vector: [3588×1]
• Groups vector also made column: [3588×1]
• boxplot(data, groups) expects both as column vectors

TECHNICAL EXPLANATION:
---------------------
For MATLAB's boxplot() function:
  boxplot(data, groups)
    - data: Single column vector of all values
    - groups: Single column vector indicating which group each value belongs to
    - Must have: length(data) == length(groups)

Our fix creates:
  all_ieis = [wt_val1; wt_val2; ...; wt_val1576; mut_val1; ...; mut_val2012]
  groups   = [1; 1; ...; 1; 2; 2; ...; 2]
             └─1576 ones─┘  └──2012 twos──┘

MATLAB QUICK REFERENCE: Concatenation
=================================================================

HORIZONTAL CONCATENATION [a, b] or [a b]:
  • Stacks arrays side-by-side (adds columns)
  • Requires: Same number of ROWS
  • Example: [1;2;3] and [4;5;6] → [1 4; 2 5; 3 6] (3×2 matrix)

VERTICAL CONCATENATION [a; b]:
  • Stacks arrays on top of each other (adds rows)
  • Requires: Same number of COLUMNS
  • Example: [1;2;3] and [4;5;6] → [1; 2; 3; 4; 5; 6] (6×1 vector)

FOR BOXPLOT:
  • Always use vertical concatenation [data1; data2]
  • Both data and groups must be column vectors
  • length(data) must equal length(groups)

TECHNICAL NOTES FOR FUTURE REFERENCE

1. MATLAB Concatenation Rules:
   - [a, b] = horizontal → requires same # rows
   - [a; b] = vertical → requires same # columns
   - Common error: mixing row and column vectors

2. Struct vs Array Length:
   - length(struct) = 1 (always!)
   - length(struct.field_array) = size of array
   - Use fieldnames(struct) to list all fields

3. Boxplot Requirements:
   - Expects: boxplot(data_vector, group_vector)
   - Both must be column vectors of equal length
   - Groups encoded as integers (1, 2, 3, ...)
